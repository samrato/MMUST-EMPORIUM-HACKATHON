Smart SMS Chat

IoT SMS Dispatch Node

Dedicated physical dispatch kits that automatically receive text requests from local health volunteers and route them directly to our central offline health database.

03

Offline GSM Network

Bypasses mobile internet coverage gaps by routing medical queries through standard mobile messaging channels instead of web data.

04

Multilingual Interface

Fully supports Swahili, English, and local dialects to ensure language is never a barrier to receiving critical health guidance.

05

Intelligent Router

Directs patients to the closest medical clinic or hospital that has the right equipment, tools, and doctors for their specific health needs.

06

Voice-to-Text Input (Speech Logging)

Allows users to ask health questions by simply speaking into the system, converting voice into text to make it accessible to everyone.

Mechanism & Process Flow

How It Works

01

User Input

Patient reports symptoms via SMS (SIM800 GSM Client) or Web portal.

02

Data Processing

MQTT broker & Port 4000 gateway bridge cleanses and routes inputs.

03

AI Analysis

Central backend classifies queries using Gemini or local BioMistral via Ollama.

04

Recommendation

AI orchestrator compiles triage advice & checks GBV safety flows.

05

Intelligent Routing

System queries KMHFR GIS database to select nearest level 1-5 facility.

06

Emergency Response

Dispatches alerts to clinics or triggers secure Counselors & Helpline 1195.
