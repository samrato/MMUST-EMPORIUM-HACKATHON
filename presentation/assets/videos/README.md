# AFYAROOT Video Assets & Playback Modes

Place your presentation video assets in this directory.

### Available Video Modes:
- **`faster.mp4`**: Fast-paced high-speed architecture & mechanism walkthrough (**Default**).
- **`normal.mp4`**: Standard-paced full display demo (supports opening in its own dedicated pop-out window).
- **`mechanism_flow.mp4`**: Detailed process flow and backend routing simulation.

### Features & Capabilities:
1. **Multi-Source Switcher**: Switch instantaneously between Fast Demo, Normal Display, and Mechanism Flow directly on the Demo Slide (Slide 10).
2. **Speed Controls Suite**: Adjust playback rate dynamically (`0.75x`, `1.0x`, `1.25x`, `1.5x` default, `1.75x`, `2.0x`, `2.5x`, `3.0x`, or `+`/`-` steppers).
3. **Pop-out Window (`video-player.html`)**: Open Normal Display (or any video) in a standalone dedicated player window for multi-monitor setups.
4. **Picture-in-Picture (PiP)**: Float the video anywhere over your screen while navigating slides.
5. **Drag-and-Drop & Custom File Upload**: Test custom video files on the fly.
